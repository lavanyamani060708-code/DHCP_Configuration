# DHCP Configuration Using Cisco Packet Tracer

## Aim
To configure a DHCP server and automatically assign IP addresses to client computers.

## Software
Cisco Packet Tracer

## Devices Used
- 2 PCs
- 1 Server-PT
- 1 Cisco 2960 Switch
- Copper Straight-Through cables

## Configuration
The server is configured with a static IP address. DHCP service is enabled to assign IP addresses automatically to the connected PCs.

## Testing
On each PC, open Desktop → IP Configuration and select DHCP. Verify that the PC receives an IP address from the configured DHCP pool.

## Result
DHCP configuration is successful when both PCs receive valid IP addresses from the DHCP server.

## Project File
